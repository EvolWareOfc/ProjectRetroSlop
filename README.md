# Project Retro Slop

> **An open-source script hub made for Retro Slop games.**

Project Retro Slop is an open-source **Roblox script hub** designed for Retro Slop games.

Scripts are provided as individual game-specific scripts and are intended to be **executed through a Roblox executor**.

The project aims to keep Retro Slop scripts organised, accessible, and open-source, allowing the community to view, improve, and contribute to the project.

## Features

- 🕹️ **Retro Slop Support**
  - Scripts designed specifically for Retro Slop-style Roblox games.

- 📜 **Game-Specific Scripts**
  - Scripts are organised by game for easier access.

- 🎨 **Custom Script Hub UI**
  - A dedicated UI for browsing and running available scripts.

- 🔓 **Open Source**
  - The source code is publicly available.
  - Contributions, improvements, and fixes are welcome.

- ⚡ **Executor-Based**
  - Scripts are intended to be loaded through a compatible Roblox executor.

## Usage

### 1. Download the Script

Clone the repository or download the script you want to use.

```bash
git clone https://github.com/EvolWareOfc/ProjectRetroSlop.git
```

### 2. Open Roblox

Launch the Roblox game that the script was designed for.

### 3. Open Your Executor

Use your preferred Roblox executor.

### 4. Load the Script

Copy the appropriate script from the `Games/` directory and load it into your executor.

### 5. Execute

Run the script while inside the supported game.

> **Important:** Scripts are game-specific. Make sure you are using the correct script for the game you are currently playing.
